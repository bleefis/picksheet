1. Open app from home screen icon

|---------|--------|

## ⚙️ Config (Gear Icon)

| Task | Action |
|------|--------|
| Edit name/ID | Tap field, type |
| Reorder | Drag **≡** handle |
| Add item | **+ Add item** |
| Delete | Tap 🗑 |
| **Save backup** | **Backup config** → save JSON |
| **Restore** | **Restore backup** → pick JSON |

---

## 💾 Backup Reminder

**Back up your config weekly** (gear → Backup config → save JSON to Google Drive)

Your item IDs live in browser storage — they're lost if you clear Chrome data
or switch phones. The JSON backup is your recovery file.

---

## 🔧 Troubleshooting

**Drag doesn't work**  
→ Grab the **≡** handle (left side), not the item name

**Email not opening**  
→ Make sure Gmail is your default email app in Android settings

**Updates not showing**  
→ Close app completely, reopen. Or: Chrome → Site settings → Clear & reset

**Lost all my IDs**  
→ Restore from your last JSON backup (gear → Restore backup)
